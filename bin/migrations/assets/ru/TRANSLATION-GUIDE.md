# Перевод сайта KOVAL Legal Group на русский — правила

Источник: `src/<файл>.json` (украинский). Результат: `tr/<тот же файл>.json`
(русский). Импорт: `bin/migrations/2026-10-03-ru-import.php`.
Проверка: `python3 bin/migrations/ru-validate.py tr/<файл>.json` — должно быть `OK`.

## Формат

- Структура JSON **точно та же**: те же ключи, тот же порядок и длина
  списков. Переводится только украинский текст в значениях.
- Не трогать: `id`, `type`, `slug`, `taxonomy`, числа, true/false, ключи
  объектов, значения без кириллицы (URL, иконки `grad`/`work`, ID, пустые
  строки).
- В пост добавить верхнеуровневый ключ `"ru_slug"`: латиница, нижний
  регистр, дефисы — транслитерация русского названия/ключевой фразы, такой
  же длины, как украинский slug. Пример: `apostyl-na-dyplom-abo-atestat` →
  `apostil-na-diplom-ili-attestat`. Не должен совпадать с украинским
  slug. Для terms.json / options.json `ru_slug` не нужен.
- HTML и Gutenberg-разметка (`<!-- wp:... -->`, теги, классы, `href`,
  `src`, `style`) — без изменений, байт в байт. Переводится только текст
  между тегами и человекочитаемые атрибуты (`alt`, `title`, `aria-label`,
  `placeholder`). Ссылки оставлять украинскими — импорт сам заменит их на
  русские страницы.
- Сохранять типографику: «ёлочки», длинное тире —, неразрывные пробелы
  (`&nbsp;`, ` `), `→`, эмодзи.

## Язык и смысл

- Естественный русский язык юридической компании, без кальки с
  украинского. Обращение на «вы» (с маленькой буквы), как в оригинале.
- **Смысл не усиливать и не ослаблять.** Компания оказывает
  консультационные и информационные услуги (требование Google Ads): если
  в оригинале «консультуємо щодо подання», то «консультируем по подаче»,
  а не «подаём». Никаких новых обещаний, гарантий, сроков, цифр.
- Rank Math `rank_math_title` / `rank_math_description` — переводить,
  длина примерно как в оригинале (title ≤ 60, description ≤ 160 символов).
- Имена в отзывах: имя остаётся, город по-русски («Марина Т., Львов»).
