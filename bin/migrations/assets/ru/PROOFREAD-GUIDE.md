# Вычитка русской версии — правила (2026-10-03)

Файлы: `tr/<файл>.json` (русский текст сайта). Оригинал для сверки смысла —
`src/<тот же файл>.json` (украинский). После правки:
`python3 bin/migrations/ru-validate.py tr/<файл>` — должно быть `OK`.

## Что исправлять

1. **Орфография и опечатки** — включая слипшиеся/лишние пробелы, двойные слова,
   латиницу внутри кириллических слов (c/с, o/о, a/а, e/е, p/р, x/х).
2. **Грамматика** — падежи, согласование рода/числа/падежа (особенно в отзывах:
   женское имя → «я обратилась», «не ожидала»), управление предлогов:
   «согласно чему» (дательный), «по приезде», «по окончании», «оплата за» → «оплата
   чего», «консультация по (дательный)».
3. **Украинизмы и кальки**: «на протяжении» вместо «протягом» ок, но не «на протязі»;
   «принимать участие» (не «приймати»); «следующий» (не «слідуючий»);
   «по вопросам» (не «по питанням»); «обратиться к/в», не «звернутися до» →
   «обратиться до»; «отличаться от», «в зависимости от»; «срок» вместо «строк»
   (в значении срока выполнения), «выписка» (не «витяг»), «справка» (не «довідка»),
   «вуз», «учреждение образования»; «ЗАГС/ДРАЦС» — по глоссарию.
4. **Пунктуация** — запятые в сложных и сложноподчинённых предложениях, при
   деепричастных оборотах, вводных словах; тире «—» с пробелами; кавычки «ёлочки»;
   без двойных знаков.
5. **Буква «ё»** — использовать последовательно там, где она есть в слове (её, ещё,
   всё (местоимение), подберём, проведённых, учёба, ребёнок, расчёт и т.п.). Не
   добавлять «ё» в слова, где её нет.
6. **Единообразие терминов** по `TRANSLATION-GUIDE.md` (глоссарий): МИД, Минюст,
   МОН, ДРАЦС, апостилирование, консульская легализация, Гаагская конвенция,
   справка о несудимости, «от 2 500 грн», «от 5 рабочих дней», «Первая консультация —
   бесплатно», «Перезвоните мне», «специалист».
7. **Естественность** — фраза должна звучать как написанная по-русски, а не
   переведённая дословно. Можно переставить слова, заменить неестественный оборот.
8. **Заглавные буквы** — заголовки и пункты списков с прописной, если так в оригинале;
   «вы» со строчной.

## Чего НЕ делать

- **Не менять смысл.** Компания оказывает консультационные услуги (требование Google
  Ads): не добавлять обещаний, гарантий, сроков, цифр, не превращать
  «консультируем по подаче» в «подаём». Если в оригинале фраза обещает больше
  консультации — оставить смысл, только отметить в отчёте.
- Не трогать структуру JSON, ключи, URL, иконки, ID, HTML-теги/атрибуты, Gutenberg-
  комментарии, `ru_slug`, `slug`. Списки, где фраза разбита на несколько пунктов
  (как в оригинале), — оставить разбиение.
- Цены, телефоны, имена компаний — без изменений.

## Отчёт

Для каждого файла — список правок в формате `было → стало` (кратко), отдельным
блоком — спорные места, которые лучше решить заказчику.
