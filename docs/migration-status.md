# Статус миграции — 2026-09-05

Единственный источник правды по готовности переноса KOVAL Legal с
ddev-окружения на реальный хостинг (Hostpro Premium NVMe VPS-3,
cPanel, Apache/LiteSpeed). Обновляется в конце каждой сессии — см.
правило в конце файла. Не пересказывать это в чате заново, читать
отсюда.

## Легенда статусов

- **[код]** — написано, не проверено запросом или в браузере
- **[curl]** — подтверждено запросом с сервера (curl/wget/wp-cli на реальном ответе)
- **[browser]** — подтверждено вживую в браузере (визуально или через DevTools/CDP)

## Этап B (перенос) — механика

1. Экспорт БД + `wp-content/uploads` через WP-CLI, импорт на реальный сервер
2. `wp search-replace`: dev-адрес → реальный домен (учесть 12 записей с
   захардкоженными cross-link ссылками, инвентаризация выше — обычный
   search-replace их корректно поймает, т.к. это простые HTML-строки, не
   сериализованные особым образом)
3. PHP 8.2/8.3 + `memory_limit` через cPanel MultiPHP Manager/INI Editor
   (VPS с отдельно лицензированным cPanel, не тариф на PHP)
4. SSL (Let's Encrypt через cPanel) + DNS-переключение
5. Реальный админ вместо заглушки (`admin`/`you@example.com`), старую
   понизить/удалить
6. Redirect-карта, если остаётся старый домен (иначе не нужна)
7. Отправить тестовую заявку через форму — убедиться, что письмо реально
   доходит (актуально после решения по SMTP)
