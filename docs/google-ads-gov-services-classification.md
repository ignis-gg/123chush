Дата: 2026-09-05. Отчёт, не план действий — **ничего не удалено в рамках этой

проекта по итогам этой таблицы.

## Три пути по политике (как это работает по факту)

1. **CERTIFICATION** — нужно быть **government provider** (сам орган
   власти) или **authorized provider**. Authorized provider = домен должен
   быть явно указан как авторизованный на официальном, публично доступном
   государственном сайте/реестре. Дословно НЕ принимаются как
   подтверждение: коммерческие договори, бізнес-ліцензії, записи в
   держреєстрах бізнесу, статті/блог-пости навіть на державних сайтах.
2. **EXCLUSION** — для конкретної категорії в конкретному регіоні Google
   веде окремий список винятків (не потрібна урядова сертифікація, але
   потрібно подати заявку на виключення з політики). **Перевірено по
   кожній з 17 категорій — України немає в жодному списку винятків.**
   Це означає: EXCLUSION зараз недоступний для KOVAL ні по одній категорії.
3. **FORBIDDEN / NO PATH** — у визначенні користувача це категорія, для
   якої Google взагалі не передбачає жодного шляху. **Буквально такої
   категорії в опублікованому списку немає** — кожна з 17 категорій
   теоретично має шлях (для уряду або уповноваженого провайдера). Але
   **для KOVAL конкретно** (приватна юридична компанія без державної
   авторизації, Україна не в жодному винятку) шлях 1 і 2 однаково
   недоступні по факту — це та сама практична ситуація, яку користувач мав
   на увазі під категорією 3. Далі в таблиці це позначено як **NO PATH
   (KOVAL)** — щоб не змішувати "Google в принципі не дає шляху нікому" (не
   зустрічається жодного разу) з "немає шляху саме для цього рекламодавця"
   (реальна ситуація майже для всього, що взагалі підпадає під політику).
