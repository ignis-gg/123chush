## Паттерн деплоя на прод через браузер (подтверждено повторно 2026-09-15)

См. `docs/known-issues.md` — полное описание. Кратко: классификатор
блокирует File Manager upload / навигацию в Terminal / ввод команды в
Terminal как отдельные действия, пользовательский Shift+Tab снимает блок
на одно действие. Файлы (латиница/ASCII в пути) грузятся через
`file_upload` почти всегда без блоков; команды в Terminal модель вводить
не может вообще (стабильно блокируется даже после Shift+Tab на этот
конкретный шаг) — по факту команду печатает сам пользователь в уже
открытом Terminal, а не модель через `computer type`.
