  типам страниц браузерным JS-скриптом (реальный computed-style
  контраст, не только code-level токены). Найдено и исправлено 3 бага:
  невидимая CTA-кнопка в блог-постах (`.related-service-card .btn`,
  ratio 1:1 — самый серьёзный из троих), `.footer-disclaimer` (3.94:1),
  breadcrumb-разделитель (1.31:1, декоративный, но тоже исправлен).
  Ноль находок после фикса на всех 9 типов страниц.
- **Приоритет 1 (tab-order) — закрыт другим методом.** Настоящая
  keyboard-Tab-навигация через это расширение **не работает в этой
  песочнице** (управляемые вкладки всегда `document.visibilityState:
  'hidden'` — новое, задокументированное ограничение среды, см.
  known-issues.md). Заменено код-уровневой проверкой: во всей теме
  ровно одно место убирает `outline` (уже с заменой, ранее подтверждено
  в браузере), везде остальном — нативный default-фокус браузера,
  WCAG-совместимый by construction. Честно помечено как [код], не
  [browser] — реальный keyboard walk остаётся невозможен здесь.

## Приоритет 1 — что осталось (по-настоящему открыто)

- Если в будущей сессии появится среда, где реальная keyboard-навигация
  через Claude in Chrome работает (другая машина/сборка расширения) —
  стоит повторить tab-order настоящим keyboard walk для полной
  уверенности вместо код-уровневого эквивалента.
- Контраст-аудит не покрывает текст поверх `background-image` (ни
  одного случая не найдено на 9 проверенных типах, но не проверялось на
  каждой из 58+ отдельных страниц по отдельности — риск только если
  где-то есть нетиповая WYSIWYG-вставка с фоном-картинкой под текстом).

## Приоритет 2

- **Resource hints / defer-async аудит** — `main.js` уже перед
  `</body>`, explicit `preconnect`/`dns-prefetch`/`preload` нигде не
  расставлены.
- **Кэш-заголовки статики на реальном хостинге** — только когда
  появится доступ к настоящему Apache/LiteSpeed (Этап C).
- **CSP-заголовок** — только с одновременной браузерной проверкой на
  реальном домене (Этап C).
- Решить, нужен ли **cookie-consent баннер** — юридическое решение, не
  техническое.
