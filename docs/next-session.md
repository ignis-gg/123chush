## Не трогать / решено окончательно

- Домен и почта (см. выше) — решение принято, не пересматривать без
  явного нового запроса пользователя.
- `git push` в этом проекте: `origin`'s push URL был перенаправлен на
  снепшот-репозиторий в какой-то момент раньше — **исправлено в этой
  сессии** (`git remote set-url --push origin
  https://github.com/ignis-gg/123chush.git`). Если снова увидите push
  на `123chush-snapshot-*` — это регресс, чинить тем же способом.
