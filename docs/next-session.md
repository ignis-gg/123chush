## Сделано в этой сессии — страница "Довідка про несудимість"

Новая консультационная страница в категории «Довідки» (соседняя с
существующим общим хабом 361/362, не замена ему) — по прямому запросу
пользователя, после явного подтверждения, что KOVAL получила
сертификацию Google Ads именно на консультационно-информационную
модель для этой темы (документ ранее удалялся 2026-09-05 за прямое
совпадение с restricted-категорией "Criminal background checks").
Текст строго консультационный (KOVAL не получает/не подаёт справку за
клиента), плюс усиленный compliance-баннер под hero (тот же паттерн,
что у легализационных страниц).

Dev пост id=394, prod id=421 (разные ID — тот же паттерн, что 361→362
для хаба «Довідки»). Задеплоено, SHA-256 сверено, рендер проверен
живьём на dev (1440/768/~500px) и на prod (768px + desktop), каталог
`/poslugy/` показывает «Довідки (2)» на обоих окружениях. Детали,
коммиты — `docs/migration-status.md`, раздел «Сесія 2026-09-21
(продовження)».

**Не проверено живьём**: настоящий mobile-viewport (375px) на prod —
только desktop и 768px через новую вкладку (resize_window синкается
только при создании вкладки, см. known-issues.md). Функционально
эквивалентно 375px для этой темы (брейкпоинты те же), но если что-то
на mobile будет выглядеть не так — смотреть сюда первым делом.

## Сделано в этой сессии — "why choose us" реформа блока "compare" на всём сайте

Пользователь указал, что заголовок блока "Це можна оформити й
самостійно" (скопирован verbatim с sitewide-шаблона на все "rich"
страницы) буквально приглашает клиента сделать всё самому — вредно для
продаж. Переписано 31 заголовок (30 услуг + хаб «Довідки»), каждый под
конкретную страницу, без изменения остального контента блока (он уже
был хорошо сформулирован). Заодно найдено и исправлено по ходу дела:

- **144** (`kopiya-sudovogo-rishennya`) — убрано прямое нарушение
  консультационной модели ("отримуємо за довіреністю без вашої
  присутності").
- **138** (`shlyubnyy-kontrakt`) — реальный **HTTP 500 на dev**
  (битые ACF-поля, дата бага — 12.09.2026, не связан с этой сессией),
  исправлен. Прод этим багом не страдал (подтверждено сайт-вайд
  сканом).

Детали, коммиты — `docs/migration-status.md`, раздел «Продовження того
ж дня — поширено на весь сайт». Все 31 URL — `200` на dev и на проде.
