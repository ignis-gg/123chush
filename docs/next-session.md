## Приоритет 1/2 — що лишилось (не з цієї сесії)

- Якщо колись з'явиться середовище, де реальна keyboard-навігація через
  Claude in Chrome працює — повторити tab-order справжнім keyboard walk.
- **Resource hints / defer-async аудит** — `main.js` вже перед
  `</body>`, explicit `preconnect`/`dns-prefetch`/`preload` ніде не
  розставлені.
- **Кэш-заголовки статики на реальному хостингу** — тільки коли з'явиться
  доступ до справжнього Apache/LiteSpeed (Этап C).
- **CSP-заголовок** — тільки з одночасною браузерною перевіркою на
  реальному домені (Этап C).
- Вирішити, чи потрібен **cookie-consent банер** — юридичне рішення, не
  технічне.
