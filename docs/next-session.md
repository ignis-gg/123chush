## Приоритет 1 — доделать после этой сессии

- **Мобильная проверка `resize_window`** — см. выше, третий раз подряд
  не срабатывает в этой песочнице; возможно требует другого окружения.
- **GA4 `contact_click`** — по состоянию на 2026-09-09 доставка
  подтверждена (DebugView), но событие ещё не появлялось в обычном
  списке событий GA4. Нужно: пользователю проверить список событий
  GA4 (Налаштування ресурсу → Події) и, если появилось, отметить
  звёздочкой как ключевое (как уже сделано для `generate_lead`).
- **Мобильный вигляд плаваючої кнопки "Подзвонити"** — код проверен
  (mobile-first дефолт), но не подтверждён живым скриншотом на реальном
  mobile viewport — упирается в ту же проблему с `resize_window`.
- **Реальная тестовая заявка через саму форму** — заполнить форму
  вживую на koval-legal.pp.ua, убедиться, что письмо доходит на
  `callcenter.via.klg@gmail.com`.
- Явно проверить SSL-сертификат отдельно (сейчас косвенно подтверждён).

## Не трогать / решено окончательно

- Домен и почта koval-legal.pp.ua — решение принято, не пересматривать
  без явного нового запроса пользователя.
- `git push` в этом проекте — `origin`'s push URL корректный
  (`https://github.com/ignis-gg/123chush.git`). Если снова увидите push
  на `123chush-snapshot-*` — это регресс, чинить тем же способом.
- Плаваюча кнопка "Подзвонити" замінює собою старий scroll-triggered
  `.sticky-cta`/`.sticky-call` — та логіка навмисно видалена, не
  відновлювати.
- Claude Code auto-mode classifier блокирует деплой-действия через
  браузер (cPanel File Manager/Terminal) независимо от CLAUDE.md — это
  ограничение самого харнесса, не проектная настройка. Рабочий обход
  описан в known-issues.md (пользователь включает "accept edits" перед
  каждой такой попыткой).
